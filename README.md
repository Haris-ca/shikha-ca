# Shikha Nanjappa & Associates

A responsive one-page website for Shikha Nanjappa & Associates, Chartered Accountants in Gonikoppa, South Kodagu.

## Contents

- Services: audit, taxation, GST, accounting, advisory, and compliance
- About the firm and its approach
- Industries and client types served
- Contact details, WhatsApp consultation links, and Google Maps location

## Run Locally

This is a static HTML site with no build step or dependencies. Open `index.html` directly in a browser, or start a simple local server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Editing

The page markup, styles, and JavaScript are contained in `index.html`. Update the contact links and firm details there when needed.
